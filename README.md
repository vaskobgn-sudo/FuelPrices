# Механата

Българска idle/tycoon игра за мобилен браузър. Наливаш ракия, купуваш постове,
трупаш звезди.

**Версия: Алфа 0.2**

## Как се играе

- **Онлайн:** публикувано на GitHub Pages. От телефон: меню ⋮ → Споделяне →
  Добавяне към началния екран. Пуска се на цял екран и работи офлайн.
- **От файл:** свали `mehanata.html` и го отвори. Един файл, без интернет,
  без инсталация.

> При отваряне от диск на Android използвай Chrome и адрес `file://`
> (напиши го в адресната лента). През файлов браузър адресът става
> `content://`, а там браузърът не дава нито икона на началния екран, нито
> надеждна памет за записа. Играта го проверява при старт и казва, ако е така.

## Устройство на проекта

```
mehanata.html            цялата игра — единственият източник на истина
site/                    произведеното за хостинг (index.html, sw.js, манифест, икони)
tools/build-site.js      прави site/ от mehanata.html
tools/make-icons.js      растеризира PNG иконите за манифеста
tools/balance.js         симулация на кривата на прогресията
tests/                   Playwright набори, node tests/run.mjs
```

`mehanata.html` няма външни зависимости, няма build стъпка и няма canvas.
Всичко нужно за игра е вътре в него; `site/` само добавя нещата, които имат
смисъл при хостинг.

## Разработка

```bash
npm i -D playwright
node tests/run.mjs                # всички набори + баланс
node tools/balance.js             # само кривата
node tools/make-icons.js          # икони за манифеста
node tools/build-site.js          # сглобява site/
```

Преди комит на промяна в `mehanata.html` пусни `node tests/run.mjs`.
Наборът пази неща, които вече веднъж са се чупили — виж `tests/README.md`.

## Правила за числата

Базовите цени и приходи на 10-те поста са фиксирани от заданието и **не се
променят**. `tools/balance.js` пази записана крива от Алфа 0.1; отклонение над
15% на който и да е праг се смята за регресия и наборът пада.

## Записът

Живее в `localStorage` на браузъра на всеки играч, вързан за адреса. Нищо не
се изпраща никъде — няма сървър, няма акаунти. Затова:

- различен адрес означава различен запис;
- **смяна на домейн трие всички записи**;
- Настройки → Резервно копие изнася записа като текст и го връща обратно.
